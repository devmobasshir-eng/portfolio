# UHD Architecture Design & Construction Website

## Files
- `index.html` — all website sections and content
- `style.css` — colors, layout, desktop/mobile responsive styling
- `script.js` — mobile menu, active navigation, project filters and contact email behavior

## Run it
1. Extract this ZIP.
2. Keep all three files in the same folder.
3. Open `index.html` in Chrome or Edge.

Internet is needed for the Google Fonts and remote Unsplash sample photos.
The contact form currently prepares an email in the visitor's email app. To receive enquiries directly, connect a backend (for example Django) or a form service.
Before publishing, replace the demo phone number, location and email address with your real details, and check image licensing/availability.
